# E-commerce-Data-Analysis-Dashboard-Olist-

## 📊 Project Overview
This project analyzes an e-commerce dataset to extract business insights related to sales performance, delivery efficiency, and customer satisfaction.

## 🧹 Data Cleaning
- Handled missing values and inconsistent data types
- Removed outliers and invalid entries
- Converted date columns to datetime format

## ⚙️ Feature Engineering
- Created delivery_time and delivery_delay metrics
- Derived KPIs such as total revenue, AOV, and delay percentage

## 📊 Analysis
- Sales trends and top product categories
- Delivery performance (on-time vs delayed)
- Customer satisfaction analysis using review scores

## 📈 Dashboard
- Built using Power BI
- Includes KPI cards, trend analysis, and interactive filters

## 🛠 Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- MySQL
- Power BI
