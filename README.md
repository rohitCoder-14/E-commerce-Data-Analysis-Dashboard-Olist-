# E-commerce-Data-Analysis-Dashboard-Olist

## 🧠 Problem Statement

This project analyzes e-commerce transaction data to uncover insights related to sales performance, customer behavior, delivery efficiency, and product trends.  
The goal is to transform raw data into actionable business insights that improve decision-making and customer satisfaction.

---

## 🎯 Objectives

* Analyze overall sales performance and revenue trends  
* Identify top-performing products and categories  
* Understand customer behavior and satisfaction levels  
* Evaluate delivery performance and delays  
* Generate actionable business insights and recommendations  

---

## 📁 Dataset Description

The dataset includes multiple interconnected tables from an e-commerce platform:

* Customers
* Sellers  
* Orders  
* Order Items  
* Products
* Payments
* Reviews     

These tables are combined to perform end-to-end business analysis.

---

## 🧹 Data Cleaning

* Handled missing values and inconsistent data types  
* Removed duplicates and invalid records  
* Treated outliers for better accuracy  
* Converted date fields into proper datetime format  

---

## ⚙️ Feature Engineering

* Created delivery_time and delivery_delay metrics  
* Derived key KPIs such as:
  * Total Revenue  
  * Average Order Value (AOV)  
  * Delay Percentage  
* Aggregated data for customer and product-level insights  

---

## 📊 Key Analysis Performed

* 📈 Sales trends over time  
* 🏆 Top-selling products and categories  
* 🚚 Delivery performance (on-time vs delayed orders)  
* ⭐ Customer satisfaction using review scores  
* 👥 Customer behavior and purchasing patterns  

---

## 📊 Dashboard

* Built using Power BI  
* Interactive visuals with filters and slicers  
* Includes:
  * KPI Cards (Revenue, AOV, Delay %)  
  * Sales trend analysis  
  * Delivery performance breakdown  
  * Customer satisfaction insights  

---

## 🛠️ Tools Used

* Python (Pandas, NumPy, Matplotlib, Seaborn)  
* SQL  
* Excel  
* Power BI  

---

## 🚀 Key Insights

* Late deliveries negatively impact customer ratings  
* Certain categories drive majority of revenue  
* Repeat customers contribute significantly to total sales  
* Seasonal trends affect order volume and revenue
